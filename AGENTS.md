# AGENTS.md

## Project

X-CSL-Updater is a Qt 5 / CMake desktop application. The main executable target is `X-CSL-Updater`.

The app downloads X-CSL package indexes, compares them with local files, and updates selected files.

## Source Map

- `CMakeLists.txt` - root CMake entry; generates `src/Info.h`.
- `src/CMakeLists.txt` - Qt executable target and install hook.
- `Description.cmake` - app metadata and version.
- `Install*.cmake` - deploy/package scripts.
- `src/main.cpp` - startup and logging.
- `src/mainwindow.*` - main UI and CLI options.
- `src/IndexStep.*` - index download/parse/check logic.
- `src/UpdateStep.*` - file update/delete/download logic.
- `src/AltitudeDefs.*` - URL and local path mapping.

Do not edit `src/Info.h`; it is generated by CMake.

## Documentation Split

- `docs/` - end-user documentation for the program.
- `readme.md` in the repo root - developer-facing documentation such as project description, licenses, and technical details.

## Local Build Dirs

## Building and Debugging

- Prefer the CLion MCP server for building, running, and debugging the application.
- Inspect the available MCP tools and existing CLion configurations first. Reuse the project's configured profiles and toolchains instead of assuming local paths or generators.
- For runtime investigation, use CLion MCP breakpoints or logpoints, stepping, call stacks, and variable inspection. Follow the `clion-debugger` skill when applicable.
- Preserve the user's run configurations and breakpoints; remove temporary agent-created breakpoints when finished.
- If the required operation is unavailable through CLion MCP, use [BUILDING.md](BUILDING.md) for command-line build and packaging instructions. Installation and packaging are Release-only.
