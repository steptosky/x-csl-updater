Спасибо, что выбрали X-CSL-Package!

X-CSL-Package — библиотека CSL-моделей самолётов и текстур для отображения трафика сети IVAO в X-Plane.
Проект разрабатывают и поддерживают команды X-AiR и StepToSky.
Используйте X-CSL-Updater, чтобы установить библиотеку и поддерживать её в актуальном состоянии.

Поддержка и совместимость

- Совместное использование X-CSL-Package с другими CSL-библиотеками или отдельными CSL-моделями официально не поддерживается.
Вы можете попробовать такую конфигурацию на свой риск, но команды X-AiR и StepToSky не несут ответственности за возникающие проблемы.
Для поддерживаемой конфигурации используйте папку CSL-библиотеки, содержащую только X-CSL-Package.
Перед заменой существующей библиотеки или проверкой совместной работы с другими моделями создайте её резервную копию.

- Использование X-CSL-Package с клиентами других виртуальных авиационных сетей официально не поддерживается.
Вы можете попробовать такую конфигурацию на свой риск, но команды X-AiR и StepToSky не несут ответственности за возникающие проблемы.
Чтобы указать другую папку для CSL-библиотеки, выберите «Меню» -> «Установить путь для CSL».
Перед проверкой такой конфигурации создайте резервную копию существующей CSL-библиотеки.

Установка и запуск

Windows:
1. Скачайте .zip-архив для Windows.
2. Распакуйте архив в выбранную вами папку.
3. Откройте папку с распакованными файлами и запустите X-CSL-Updater.exe.

Linux:
1. Скачайте архив .tar.gz для Linux.
2. Распакуйте архив в выбранную вами папку.
3. Откройте терминал в папке с распакованным скриптом X-CSL-Updater.sh и выполните:
   ./X-CSL-Updater.sh

macOS:
1. Скачайте образ диска .dmg для macOS.
2. Откройте образ диска и перетащите X-CSL-Updater.app в папку «Программы» (Applications).
3. Запустите X-CSL-Updater из папки «Программы».

--------------------------------------------------------------------------------
Установка и обновление CSL-пакетов (для всех систем)

1. Нажмите «Обзор» и откройте папку, в которой установлен X-Plane. Выберите:
   - Windows: исполняемый файл X-Plane (.exe).
   - Linux: исполняемый файл X-Plane.
   - macOS: приложение X-Plane (.app).
   Если нужно указать другую папку для CSL-библиотеки, вместо этого выберите «Меню» -> «Установить путь для CSL».
2. Нажмите «Индексировать», чтобы сравнить локальные CSL-файлы с индексом пакетов на сервере.
3. Дождитесь завершения индексации. В столбце «Статус» будет указано, какие пакеты нужно установить или обновить.
4. Выделите пакеты, которые хотите установить или обновить. Чтобы выбрать несколько пакетов,
   щёлкайте по ним, удерживая Ctrl в Windows или Linux либо Command в macOS.
   Чтобы выбрать все пакеты, нажмите «Выделить всё».
5. Нажмите «Обновить» и дождитесь завершения операции.

Параметры командной строки

  -h, --help                         Показать справку и выйти.
  -v, --version                      Показать версию и выйти.
  -t, --sim-target-dir <папка>        Указать корневую папку X-Plane.
      --custom-target-dir <папка>    Указать папку CSL-библиотеки напрямую.
  -i, --index-auto-start             Начать индексацию автоматически.
  -d, --verbose                      Включить подробное журналирование.

Заключайте пути с пробелами в кавычки. Выбранная папка сохраняется для следующих запусков.
Режим --custom-target-dir пропускает проверки X-Plane, исключает дополнительные файлы
клиента и имеет приоритет над --sim-target-dir. Смена папки в окне программы при этом
недоступна до следующего запуска.
Индексация не запускает обновление: выберите пакеты и нажмите «Обновить» в окне программы.
Параметры -i и -d действуют только для текущего запуска. При каждом запуске log.txt
рядом с исполняемым файлом перезаписывается.
В Windows параметры --help и --version показывают справку и версию в отдельном окне,
а не в терминале. Нажмите «ОК», чтобы закрыть это окно и завершить работу программы.
